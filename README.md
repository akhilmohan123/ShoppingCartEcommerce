# ShoppingCartEcommerce
Smart facial recognition product recommendations + Secure checkout & password recovery

🔥 Features
FaceAPI.js Integration – Real-time facial detection for personalized product recommendations

Forgot Password Flow – Secure token-based reset via Nodemailer

Razorpay Payment Gateway – Seamless checkout experience

Node.js Backend – Robust API handling & authentication

🛠 Tech Stack
Frontend: HTML5, CSS3, JavaScript, Bootstrap

Backend: Node.js, Express

APIs & Libraries:

FaceAPI.js (AI/ML face detection)

Razorpay (Payments)

Nodemailer (Transactional emails)

Live Link : https://shopping-cart-gray-nu.vercel.app/
